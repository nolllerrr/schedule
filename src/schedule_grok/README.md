# Реакции на расписание

Генерация разговорных реплик одногруппника на публикации и изменения расписания в Telegram через Grok CLI. Модуль возвращает текст реакции или `None` и не отправляет сообщения напрямую.

## Что умеет

Генерирует короткую разговорную реакцию с ситуативным юмором; мат допустим, но не обязателен.
Выбирает одну деталь расписания и не делает выводов о сложности предмета по его названию.
Понимает дистанционные пары: сокращение «Д/О» означает дистант из дома, очные пары кончаются раньше.
Не блокирует бота: при сбое или таймауте возвращает `None`, основная рассылка продолжается штатно.
Вывод CLI ограничен 128 КиБ stdout и 64 КиБ stderr; одновременно выполняется один subprocess. Окружение процесса не содержит токен Telegram и ключ аналитики. Семантика отправки — best-effort; порядок, согласие чата и ограничения очереди описаны в [защите Grok](../../docs/grok-safety.md).
Настраивается через переменные окружения, файл `config.json` и аргументы вызова.

## Как пользоваться

Подключите функцию генерации в обработчик рассылки после отправки основного сообщения:

```python
from schedule_grok import generate_grok_reaction

# 1. Отправка расписания
await send_schedule_notification(chat_id, schedule_text)

# 2. Фоновая генерация реакции
reaction = await generate_grok_reaction(
    schedule_text,
    enabled=settings.GROK_REACTIONS_ENABLED,
    cli_path=settings.GROK_CLI_PATH,
    timeout=settings.GROK_TIMEOUT_SECONDS,
)

# 3. Отправка реакции в чат
if reaction:
    await send_reaction(chat_id, reaction)
```

Вместо полного текста расписания можно передавать текст изменений (`diff`).

## Настройка

В каталоге проекта в `.env`:

```ini
GROK_REACTIONS_ENABLED=true
GROK_CLI_PATH=grok
GROK_TIMEOUT_SECONDS=30
```

Дополнительные параметры и промпт задаются в `config.json`. Путь к файлу конфигурации можно переопределить через `GROK_REACTION_CONFIG`.
Параметр `allow_profanity: true` допускает мат, не добавляя к промпту требований его использовать; `false` добавляет запрет на мат и его замаскированные варианты.
