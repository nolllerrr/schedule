# Bundled font

Noto Sans Regular and SemiBold are distributed unchanged under the SIL Open Font
License 1.1; the complete copyright and license text is in `OFL.txt`.

Source: the archived official [notofonts/noto-fonts repository](https://github.com/notofonts/noto-fonts),
`hinted/ttf/NotoSans/NotoSans-Regular.ttf` and `NotoSans-SemiBold.ttf`.
The files are bundled in the Python package so offline Docker rendering does not
depend on host fonts or an operating-system package repository.
