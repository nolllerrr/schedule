# Telegram-бот расписания

Расписание Петрозаводского архитектурно-строительного техникума в Telegram. Бот получает Excel с сайта техникума и показывает занятия студентам, преподавателям и чатам учебных групп. Поддерживается корпус 1.

## Что умеет

- Показывает расписание на сегодня, завтра, ближайшие семь дней и выбранную опубликованную дату.
- Отправляет [PNG-карточку дня](docs/schedule-cards.md) по кнопке «🖼 Карточка» для студентов и чатов учебных групп.
- Кнопка актуального расписания показывает сегодняшний день до окончания последней пары выбранной группы или преподавателя, затем — ближайший опубликованный день с занятиями.
- Запоминает группу студента или выбранного преподавателя.
- Проверяет несколько опубликованных файлов и сообщает о новых занятиях, исправлениях и переносах, относящихся к подписчику.
- Сохраняет связь предмета, преподавателя и аудитории для распознанных подгрупп.
- Работает в групповых чатах и автоматически обновляет закреплённое расписание.
- Сохраняет загруженные данные и предупреждает о возможной устарелости.

## Как пользоваться

В личном чате отправьте `/start` и выберите группу или преподавателя. Расписание открывается кнопками через `/menu`; уведомления и смена профиля доступны на нижней клавиатуре.

В групповом чате администратор выбирает группу через `/setup`, после чего участники открывают расписание командой `/menu`.

[Подробная инструкция](docs/usage.md)

## Запуск своего экземпляра

Нужны Docker и Docker Compose. В каталоге проекта:

1. Скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN`, полученный у [BotFather](https://t.me/BotFather). Для команд администратора добавьте свой Telegram ID в `ADMIN_TELEGRAM_IDS`.
3. Запустите:

```sh
docker compose up --build -d
```

[Установка и запуск без Docker](docs/setup.md) · [Все настройки](docs/configuration.md)
